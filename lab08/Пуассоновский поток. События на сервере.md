Цель - смоделировать поток запросов на сервер. Использовать модель простейшего потока событий, где событие — это поступление запроса на сервер. 

## Теоретическая часть
Простейший поток запросов описывается распределением Пуассона.
Число запросов за интервал времени $T$:
$P(X=k)=\frac{(\lambda T)^k e^{-\lambda T}}{k!}$, где $\lambda$ - интенсивность потока, $T$ - интервал времени, $k$ - число запросов.

Характеристики:
$M[X]=\lambda T$
$D[X]=\lambda T$

Свойства:
- Стационарность - вероятность поступления определённого числа запросов зависит только от длины интервала времени, а не от его положения на оси времени.
- Ординарность - за очень маленький промежуток времени может произойти не более одного события.
- Отсутствие последействия - будущие события не зависят от прошлых.

## Код
Моделирование выполняется заданное количество раз. Генерируется случайный интервал времени между запросами с экспоненциальным распределением. Переходим к моменту следующего запроса. Если запрос пришел до конца интервала T, то увеличиваем число запросов. Сохраняем число запросов данного эксперимента.
Подсчитываем сколько раз встретилось каждое число запросов. Найденное число запросов делим на всё количество экспериментов.

```
for (int exp = 0; exp < n; exp++)
{
    double t = 0;
    int x = 0;
    while (t < T)
    {
        double r = random.NextDouble();
        double dt = -Math.Log(1 - r) / lam;
        t += dt;
        if (t <= T)
            x++;
        else
            listBox1.Items.Add($"Число запросов за время T = {x}");
    }
    x_history.Add(x);
}
int maxReq = x_history.Max();
int[] counts = new int[maxReq+ 1];
foreach (int value in x_history)
{
    counts[value]++;
}
double[] probabilities = new double[maxReq + 1];
for (int i = 0; i <= maxReq; i++)
{
    probabilities[i] = (double)counts[i] / n;
}
```
