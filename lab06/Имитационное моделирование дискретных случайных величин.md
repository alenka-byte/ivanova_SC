## Часть 1. Дискретная случайная величина

Теоретические вероятности: $р_1 = 0.2; p_2 = 0.15; p_3 = 0.1; p_4 = 0.25; p_5 = 0.3$.

* **Теоретические характеристики:**
$M[X]=\sum_{i=1}^{5}x_ip_i$
$D[X]=\sum_{i=1}^{5}(x_i-M[X])^2p_i$
* **Эмпирические характеристики:**
$\overline{X}=\frac{1}{N}\sum_{j=1}^{N}X_j$
$S^2=\frac{1}{N-1}\sum_{j=1}^{N}(X_j-\overline{X})^2$
$P^{*}(X=i)=\frac{n_i}{N}$, $n_i$ - частота значения $i$
* **Относительные погрешности:**
$\delta_{mean}=\frac{|\overline{X}-M[X]|}{M[X]}*100$%
$\delta_{var}=\frac{|S^2-D[X]|}{D[X]}*100$%
* **Критерий $\chi^2$**
Статистика критерия:
$\chi^2=\sum_{i=1}^{5}\frac{(n_i-Np_i)^2}{N*p_i}$, где $n_i$ - наблюдаемая частота значения $i$; $Np_i$ - ожидаемая частота
Число степеней свободы:
$df=5-1=4$
Критическое значение для $\alpha=0.05$:
$\chi_{крит}^2(df=4)=9.488$
Правило принятия гипотезы:
Если $\chi^2<=\chi_{крит}^2$, то гипотеза о соответствии распределений принимается, иначе отвергается

## Часть 2. Нормальная случайная величина

Среднее значение: 5
Дисперсия: 3
Уровень значимости: $\alpha=0.05$

**Генерация нормальной случайной величины методом Бокса-Мюллера**
$Z_1=\sqrt{-2lnU_1}cos(2\pi U_2)$ - независимая стандартная случайная величина
$Z_2=\sqrt{-2lnU_1}sin(2\pi U_2)$ - независимая стандартная случайная величина
$U_1,U_2$ - равномерно распределенные случайные числа
$X=\mu+\sigma Z_0$, где $\sigma=\sqrt{\sigma^2}$
Метод основан на преобразовании равномерного распределения в нормальное через полярные координаты. Паре $(U_1,U_2)$ соответствует точка в единичном квадрате, которая преобразуется в точку на плоскости с независимыми нормальными координатами.

**Эмпирические характеристики:**
$\overline{X}=\frac{1}{N}\sum_{j=1}^{N}X_j$
$S^2=\frac{1}{N-1}\sum_{j=1}^{N}(X_j-\overline{X})^2$

**Относительные погрешности:**
$\delta_{mean}=\frac{|\overline{X}-M[X]|}{M[X]}*100$%
$\delta_{var}=\frac{|S^2-D[X]|}{D[X]}*100$%

**Нормальное распределение**
$f(x)=\frac{1}{\sigma \sqrt{2\pi}}exp(-\frac{(x-\mu)^2}{2\sigma^2})$ - плотность распределения вероятности
$F(x)=\int_{-\infty}^{x}f(t)dt$

**Критерий $\chi^2$**
Статистика критерия:
$\chi^2=\sum_{i=1}^{k}\frac{(n_i-Np_i)^2}{N*p_i}$, где $n_i$ - наблюдаемая частота значения $i$; 
$p_i$ - теоретическая вероятность попадания в интервал
$Np_i$ - ожидаемая частота
Число степеней свободы:
$df=k-r-1$, 
$k=log_2N+1$ - количество интервалов, $r=2$ - число оцениваемых параметров
Правило принятия гипотезы:
Если $\chi^2<=\chi_{крит}^2$, то гипотеза о соответствии распределений принимается, иначе отвергается

**Построение гистограммы плотности**
1. Найдем минимум и максимум выборки
2. Вычислим количество интервалов по правилу Стерджеса: $k=log_2N+1$N+1⌉
3. Вычислим ширину интервала: $\Delta x=\frac{max-min}{N\Delta x}$
4. Подсчитаем частоты $n_i$​ (сколько значений попало в i-й интервал)
5. Вычислим плотность: $\hat{f}(x_i)=\frac{n_i}{N⋅\Delta x}​​$
