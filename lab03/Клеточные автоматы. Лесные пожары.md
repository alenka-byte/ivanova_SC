#### Инициализация леса и добавление водоемов
Сначала заполним всю матрицу нулями, где ноль - это пустая клетка. Далее мы заполняем матрицу случайными числами от 0 до 1 и сравниваем его с порогом - это вероятность того, что вырастет дерево и по умолчанию она равна 0,7. Если меньше, то будет дерево, если больше, то остается пустота. Стоит отметить, что мы не берем в расчет граничные значения, так как тогда не нужно обрабатывать особые случаи на границах.
Далее создаем реку. А озера создаем с помощью цикла, в котором:
- **`center_y = np.random.randint(20, 180)`** - случайная координата Y центра (от 20 до 179)
- **`center_x = np.random.randint(20, 180)`** - случайная координата X центра (от 20 до 179)
- **`radius = np.random.randint(3, 10)`** - случайный радиус от 3 до 9 пикселей
- **`draw.disk((center_y, center_x), radius)`** - функция из skimage, которая возвращает координаты всех точек круга
    - `rr` - массив строк (y-координаты)
    - `cc` - массив столбцов (x-координаты)
- **`self.x[rr, cc] = water`** - все клетки внутри круга становятся водой

#### Создание облака
В начале мы задали координаты центра облака и определим `shape_parameter`- это параметр, определяющий форму облака. Создаем прямоугольник и и с помощью уравнения эллипса находим точки, которые попали внутрь эллипса.
```
def create_rain_cloud(self, center_y, center_x, shape_parameter=8):  
    """Создает облако в форме эллипса"""  
    cloud = []  
    for dy in range(-shape_parameter, shape_parameter + 1):  
        for dx in range(-shape_parameter * 2, shape_parameter * 2 + 1):  
            if (dx / (shape_parameter * 1.5)) ** 2 + (dy / shape_parameter) ** 2 <= 1:  
                cloud.append((dy, dx))  
    return cloud
```

#### Эффект дождя
Проверяем не выключено ли облако в чек-боксе. Нам необходимы следующие параметры:
* координаты центра облака
* копия массива для изменений
* радиус действия дождя
Создаем квадрат со стороной `2*radius + 1` и, используя уравнение круга: **dy² + dx² ≤ radius²**, проверяем только точки внутри круга. Далее необходимо преобразовать координаты из относительных (смещение относительно центра) в абсолютные (реальные координаты на карте) и проверить не вышли ли мы за границы карты. Если в клетке огонь и пройдена проверка эффективности, то клетка становится пустой
Примечание: дождь может быть мелким и тогда он не эффективен в тушении.
```
def apply_rain(self, x, cloud_center):  
    """Применяет эффект дождя - тушит огонь в области облака"""  
    if not self.cloud_active:  
        return x.copy()  
  
    cy, cx = cloud_center  
    rain_affected = x.copy()  
    radius = self.rain_radius  
  
    for dy in range(-radius, radius + 1):  
        for dx in range(-radius, radius + 1):  
            if dy ** 2 + dx ** 2 <= radius ** 2:  
                y, x_coord = cy + dy, cx + dx  
                if 0 <= y < self.ny and 0 <= x_coord < self.nx:  
                    if rain_affected[y, x_coord] == fire:  
                        if np.random.random() < self.rain_effectiveness:  
                            rain_affected[y, x_coord] = empty  
    return rain_affected
```

#### Подсчет горящих соседей
Проходим по всем соседям и, если не вышли за границы и клетка соседа горит, то увеличиваем счетчик.
```
def count_neighbor_fires(self, x, iy, ix):  
    """Подсчитывает количество горящих соседей вокруг клетки"""  
    fire_count = 0  
    for dy, dx in neighbourhood:  
        ny, nx_coord = iy + dy, ix + dx  
        if 0 <= ny < len(x) and 0 <= nx_coord < len(x[0]):  
            if x[ny, nx_coord] == fire:  
                fire_count += 1  
    return fire_count
```

#### Один шаг симуляции
Сначала тушим огонь дождем и создаем копию изменений. Проходимся по каждой клетке, не включая границы. Далее перечислим условия изменения клетки:
* Если клетка **пустая** и не больше вероятности роста, то вырастет дерево.
* Если в клетке **вода**, то она не меняется.
* Если в клетке **дерево**, то проверяем соседей. Если у сосед "горит" и он находится по диагонали, то у дерева меньше шансов загореться. Если сосед "не горит", то в дерево может ударить молния и оно загорится.
* Если в клетке **огонь** и все соседи "горят", то клетка "выгорает" и становится пустой. Иначе есть вероятность, что она сама потухнет и станет пустой.
```
def iterate(self, x, cloud_pos):  
    """Один шаг симуляции"""  
    # Сначала применяем дождь от облака    x_after_rain = self.apply_rain(x, cloud_pos)  
    x1 = x_after_rain.copy()  
  
    for ix in range(1, self.nx - 1):  
        for iy in range(1, self.ny - 1):  
            if x_after_rain[iy, ix] == empty and np.random.random() <= self.p:  
                x1[iy, ix] = tree  
  
            elif x_after_rain[iy, ix] == water:  
                x1[iy, ix] = water  
  
            elif x_after_rain[iy, ix] == tree:  
                for dx, dy in neighbourhood:  
                    if x_after_rain[iy + dy, ix + dx] == fire:  
                        modified_probability = 0.478  
                        if abs(dx) == abs(dy):  
                            modified_probability *= 0.8  
                        if np.random.random() < modified_probability:  
                            x1[iy, ix] = fire  
                            break  
		            else:  
		                if np.random.random() <= self.f:  
		                    x1[iy, ix] = fire  
  
            elif x_after_rain[iy, ix] == fire:  
                neighbor_fires = self.count_neighbor_fires(x_after_rain, iy, ix)  
                if neighbor_fires >= 8:  
                    x1[iy, ix] = empty  
                else:  
                    if np.random.random() < 0.1:  
                        x1[iy, ix] = empty  
                    else:  
                        x1[iy, ix] = fire  
  
    return x1
```
